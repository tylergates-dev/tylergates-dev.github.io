Projects

Enterprise and automation (PowerShell)

  • Microsoft_Powershell_Projects

    PowerShell scripts for Intune deployments, SharePoint, Microsoft Graph and security policy enforcement, published as sanitized templates with company identifiers removed. Other administrators can reuse production scripts without exposing company data.

  • SharePoint-Hardware-Asset-Tracker

    Creates a SharePoint Online device inventory list with PnP PowerShell: custom columns, column formatting and filtered views. A repeatable script replaces manual list setup, so the inventory schema is identical every time it is built.

  • Intune_Joined_Device_Cleanup

    Every Intune enrolled Windows device gets the same lean baseline with no hands on work. The scripts, deployed through Intune, strip Bing search integration, built in Appx packages, optional capabilities and optional features from Entra joined devices.

  • RingCentral_Deployment

    Silent install and uninstall scripts for RingCentral for Windows, deployed through Intune. Devices receive the app with no user or technician action.

  • Sanitize-Scripts

    Scans PowerShell scripts for secrets, tokens, email addresses, domain names and organization identifiers, then writes sanitized copies plus a mapping of every replacement. Originals are never modified, so secrets and organization identifiers get caught before internal scripts are published.

  • Get-IntuneUserDeviceReport

    Who has which device, and is it compliant? One CSV answers both. The script pulls every Intune managed device and its assigned user through Microsoft Graph, then joins compliance, ownership, OS and last check in data.

Homelab and infrastructure

  • Security monitoring stack

    Security monitoring on Proxmox, every service in its own Linux container: Wazuh SIEM collecting from every network segment, Suricata IDS on a mirrored switch port, a honeypot, scheduled OpenVAS vulnerability scans and Uptime Kuma for service health.

  • Multi VLAN network architecture

    Home network segmented into VLANs on an Aruba managed switch, with port security, traffic mirroring and syslog forwarding to the SIEM. DNS is filtered by Pi-hole and sent upstream encrypted through Unbound over DNS over TLS. An opt in WireGuard VPN gateway serves selected devices.

  • Remote DNS privacy deployment

    Pi-hole on a Raspberry Pi Zero 2W at a second site, managed over Tailscale, with a hardware watchdog for unattended recovery. Blocks over 1.2 million domains through curated blocklists.
